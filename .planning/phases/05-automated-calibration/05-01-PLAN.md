  <files>scripts/calibration-pipeline.py</files>
  <action>
Create `scripts/calibration-pipeline.py` -- the main daily pipeline orchestrator. Follow the subprocess pattern from `daily-backtest.py` but extend it significantly.

**Structure:**

1. **Imports and setup:** `sys.path.insert` for `src/kalshi/`, import `notify_whatsapp`, `_atomic_write_json`, `setup_logging`, `setup_unbuffered`. Define paths:
   - `PROJECT_DIR` = parent.parent of script
   - `SCRIPTS_DIR` = PROJECT_DIR / "scripts"
   - `DATA_DIR` = PROJECT_DIR / "data"
   - `BASELINES_PATH` = DATA_DIR / "calibration-baselines.json"
   - `LOG_DIR` = DATA_DIR / "logs" / "calibration"
   - `RESULTS_PATH` = DATA_DIR / "backtest-results.json"

2. **Constants:**
   - `DRIFT_THRESHOLD = 0.10` (10% degradation)
   - `MIN_SAMPLES = 10` (minimum trades before drift detection activates)
   - `STAGES` list of tuples: `(name, script_path, args, timeout_seconds)`
     - `("reconcile", SCRIPTS_DIR / "reconcile-trades.py", [], 120)`
     - `("backfill", SCRIPTS_DIR / "backfill-settlements.py", [], 180)`
     - `("backtest", SCRIPTS_DIR / "backtest.py", ["--save"], 120)`
     - `("calibrate", SCRIPTS_DIR / "calibrate-sigma.py", ["--json"], 300)`

3. **`run_stage(name, script, args, timeout)` function:**
   - Runs subprocess with `[sys.executable, str(script)] + args`
   - `capture_output=True, text=True, timeout=timeout`
   - Returns dict: `{"success": bool, "stdout": str, "stderr": str, "duration_s": float}`
   - On `subprocess.TimeoutExpired`: returns success=False, stderr=f"Timeout after {timeout}s"
   - On other exceptions: returns success=False with exception message

4. **`run_pipeline()` function:**
   - Iterates over STAGES, calls `run_stage()` for each
   - Collects results dict keyed by stage name
   - Strategy: continue on failure (each stage is independent enough). Log failures but proceed.
   - For the "calibrate" stage, parse stdout as JSON if successful (proposed calibration params for later use by Plan 05-02)
   - Returns: `{"stages": {...}, "proposed_calibration": parsed_json_or_None}`

5. **`load_baselines()` function:**
   - Reads `BASELINES_PATH`, returns dict or None if missing/corrupt
   - Pattern: `json.loads(path.read_text())` with try/except

6. **`save_baselines(baselines)` function:**
   - Uses `_atomic_write_json(BASELINES_PATH, baselines)`

7. **`initialize_baselines(backtest_results)` function:**
   - Called on first run when no baselines file exists
   - Extracts from backtest_results:
     - `aggregate`: `{"brier": results["brier_score"], "n": results["n_evaluated"]}`
     - `per_bot`: For each bot in `results["per_bot"]`, extract `{"brier": bot["brier_score"], "n": bot["n_evaluated"]}` -- skip bots where brier_score is None
     - `per_city`: For each city in `results.get("per_city_brier", {})`, extract `{"brier": city["brier"], "n": city["n"]}`
   - Adds metadata: `"initialized_at": datetime.now(UTC).isoformat()`, `"last_updated": same`
   - Saves via `save_baselines()`
   - Returns the baselines dict

8. **`check_drift(baselines, current_results)` function:**
   - Returns list of drift findings: `[{"entity": str, "type": "aggregate"|"bot"|"city", "baseline_brier": float, "current_brier": float, "change_pct": float, "drifted": bool, "reason": str}]`
   - Check aggregate: compare `baselines["aggregate"]["brier"]` vs `current_results["brier_score"]`
   - Check per-bot: iterate `baselines.get("per_bot", {})`, compare against `current_results["per_bot"]`
   - Check per-city: iterate `baselines.get("per_city", {})`, compare against `current_results.get("per_city_brier", {})`
   - For each entity:
     - If baseline or current brier is None: reason="insufficient data", drifted=False
     - If baseline_n < MIN_SAMPLES or current_n < MIN_SAMPLES: reason=f"low sample (baseline={bn}, current={cn})", drifted=False
     - If baseline_brier == 0: reason="baseline is zero", drifted=False
     - Otherwise: `change = (current - baseline) / baseline`, drifted = change > DRIFT_THRESHOLD
   - Returns all findings (including non-drifted) for the log

9. **`format_whatsapp_summary(stage_results, drift_findings, any_stage_failed)` function:**
   - Keep message under 500 characters
   - Format:
     ```
     Kalshi Calibration Pipeline

     Stages: 4/4 passed (or "3/4 passed, FAILED: backfill")

     [If any drifted:]
     DRIFT DETECTED:
     - weather: 0.330 -> 0.400 (+21%)
     - MIA: 0.640 -> 0.750 (+17%)
     Recommendation: Review calibration

     [If none drifted:]
     All models healthy (N entities checked)
     ```
   - Only list drifted entities (not all). Aggregate healthy status into one line.

10. **`write_pipeline_log(run_at, stage_results, drift_findings, whatsapp_sent, total_duration)` function:**
    - Creates `LOG_DIR / f"pipeline-{date_str}.json"` (date_str = YYYY-MM-DD)
    - Full details per user decision: all stage results, all drift findings (including healthy), timing
    - Uses `_atomic_write_json`
    - `LOG_DIR.mkdir(parents=True, exist_ok=True)` before write

11. **`main()` function with argparse:**
    - Flags: `--dry-run` (run pipeline but don't send WhatsApp), `--update-baseline` (re-snapshot baselines from current results)
    - Flow:
      a. `setup_unbuffered()`
      b. `log = setup_logging("calibration-pipeline")`
      c. Run `run_pipeline()` to get stage results
      d. Load `backtest-results.json` (should have been updated by backtest stage)
      e. Load or initialize baselines
      f. Run `check_drift(baselines, results)`
      g. If `--update-baseline`: call `initialize_baselines(results)` and log
      h. Format WhatsApp summary
      i. Send WhatsApp (unless `--dry-run`)
      j. Write pipeline log
      k. Log summary to stdout
      l. Exit code 0 (even if drift detected -- drift is informational, not an error)

**Important constraints:**
- Do NOT run `calibrate-sigma.py --save` in the pipeline. Only `--json` to capture proposed params. Auto-applying calibration is explicitly out of scope.
- Continue on stage failure. A failed reconcile should not prevent backtest from running on already-reconciled data.
- Baselines only update on `--update-baseline` flag, never automatically on detection runs.
- Per-city drift should be reported independently even if aggregate weather Brier is fine.
