<task type="auto">
  <name>Task 1: Add calibration suggestion generation and apply mechanism</name>
  <files>scripts/calibration-pipeline.py</files>
  <action>
Extend `scripts/calibration-pipeline.py` (created in Plan 05-01) with suggestion generation and apply functionality.

**1. Add constants:**
```python
SUGGESTION_DIR = DATA_DIR / "calibration-suggestions"
CALIBRATION_PATH = PROJECT_DIR / "config" / "calibration.json"
CALIBRATION_BACKUP_PATH = PROJECT_DIR / "config" / "calibration-backup.json"
SUGGESTION_IMPROVEMENT_THRESHOLD = 0.05  # 5% Brier improvement required to generate suggestion
```

**2. Add `evaluate_suggestion(proposed_calibration, current_calibration)` function:**
- Compare proposed vs current calibration to determine if a suggestion should be generated
- For each section that has data (weather, nws, album_sales, box_office, ensemble):
  - Extract the section's Brier score from both proposed and current (field name: `"brier"` or `"brier_score"` -- check the actual calibrate-sigma.py output structure)
  - If proposed Brier < current Brier: compute improvement_pct = (current - proposed) / current
- Calculate aggregate improvement across sections with data
- Return: `{"should_suggest": bool, "improvements": dict, "aggregate_improvement_pct": float}`
- Only `should_suggest=True` when aggregate improvement > SUGGESTION_IMPROVEMENT_THRESHOLD (5%)
- If current calibration doesn't exist or has no data, always suggest (first calibration)

**3. Add `generate_suggestion(proposed_calibration, current_calibration, improvements)` function:**
- `SUGGESTION_DIR.mkdir(parents=True, exist_ok=True)`
- Filename: `calibration-suggestion-{YYYY-MM-DD}.json` (date-stamped, never overwritten -- if same-day suggestion exists, append `-N` counter)
- Content:
  ```json
  {
      "generated_at": "ISO timestamp",
      "trigger": "weather global Brier improved 12% (0.330 -> 0.290)",
      "current_calibration": { ... },
      "proposed_calibration": { ... },
      "improvements": {
          "weather": {"before": 0.330, "after": 0.290, "improvement_pct": 12.1},
          ...
      },
      "recommendation": "Apply: weather sigma improved. Run: python3 scripts/calibration-pipeline.py --apply-suggestion data/calibration-suggestions/calibration-suggestion-2026-02-28.json"
  }
  ```
- Use `_atomic_write_json` to write
- Return the suggestion file path

**4. Add `apply_suggestion(suggestion_path)` function:**
- Load suggestion JSON from the provided path
- Extract `proposed_calibration` from it
- Backup current `config/calibration.json` to `config/calibration-backup.json` (using `shutil.copy2`)
- Write proposed calibration to `config/calibration.json` using `_atomic_write_json`
- Log the diff (which sections changed)
- Then re-snapshot baselines: load `data/backtest-results.json` and call `initialize_baselines()` to update baselines to reflect the new calibration acceptance
- Return success bool

**5. Update `main()` argparse:**
- Add `--apply-suggestion` flag that takes a file path argument: `parser.add_argument("--apply-suggestion", type=str, metavar="PATH", help="Apply a calibration suggestion file")`
- If `--apply-suggestion` is provided:
  - Call `apply_suggestion(args.apply_suggestion)`
  - Print confirmation
  - Exit (don't run the full pipeline)
- In the normal pipeline flow (after drift detection):
  - If `run_pipeline()` returned `proposed_calibration` (calibrate stage succeeded):
    - Load current `config/calibration.json`
    - Call `evaluate_suggestion(proposed, current)`
    - If `should_suggest`: call `generate_suggestion()` and mention in WhatsApp summary
  - Update `format_whatsapp_summary` call to include suggestion info (add a line like "Calibration suggestion generated -- review data/calibration-suggestions/...")

**6. Update `write_pipeline_log()` to include suggestion info:**
- Add `"suggestion_generated": bool` and `"suggestion_path": str_or_null` to the log JSON

**Important constraints:**
- Never auto-apply calibration. The `--apply-suggestion` flag is an explicit human action.
- Suggestion file naming must be unique (never overwrite). Append `-2`, `-3` etc if same-day file exists.
- Load current calibration from `config/calibration.json`, not from the proposed output.
- The `--apply-suggestion` path is a completely separate flow from the pipeline run -- it just applies and exits.

**Import pattern:** Use `importlib.util.spec_from_file_location` to load `calibration-pipeline.py` (hyphenated filename):
```python
import importlib.util
import sys
from pathlib import Path

SCRIPT_PATH = Path(__file__).resolve().parent.parent / "scripts" / "calibration-pipeline.py"

def _load_pipeline():
    """Load calibration-pipeline.py module."""
    spec = importlib.util.spec_from_file_location("calibration_pipeline", SCRIPT_PATH)
    mod = importlib.util.module_from_spec(spec)
    # Need to stub kalshi_auth before loading
    import types
    mock_auth = types.ModuleType("kalshi_auth")
    mock_auth.notify_whatsapp = lambda *a, **kw: None
    mock_auth._atomic_write_json = lambda *a, **kw: None
    mock_auth.setup_logging = lambda name: __import__("logging").getLogger(name)
    mock_auth.setup_unbuffered = lambda: None
    mock_auth.PROJECT_DIR = Path(__file__).resolve().parent.parent
    sys.modules["kalshi_auth"] = mock_auth
    spec.loader.exec_module(mod)
    return mod
```

**Tests to write:**

1. **`test_check_drift_detects_degradation`** -- Baseline brier 0.30, current 0.35 (16.7% degradation > 10%). Verify drifted=True.

2. **`test_check_drift_no_drift_within_threshold`** -- Baseline 0.30, current 0.32 (6.7% < 10%). Verify drifted=False.

3. **`test_check_drift_skips_low_sample`** -- Baseline n=5, current n=20. Both below MIN_SAMPLES=10. Verify drifted=False, reason contains "low sample".

4. **`test_check_drift_per_city_independent`** -- Aggregate fine but one city drifted. Verify the city finding shows drifted=True even though aggregate is drifted=False.

5. **`test_check_drift_handles_none_brier`** -- Bot with brier_score=None in current results (no evaluated trades). Verify drifted=False, reason="insufficient data".

6. **`test_initialize_baselines_structure`** -- Given backtest results dict, verify baselines has correct structure: initialized_at, last_updated, aggregate, per_bot, per_city. Verify bots with None brier_score are excluded.

7. **`test_evaluate_suggestion_triggers_on_improvement`** -- Proposed weather Brier 0.28, current 0.33 (15% improvement > 5%). Verify should_suggest=True.

8. **`test_evaluate_suggestion_skips_negligible`** -- Proposed 0.305, current 0.309 (1.3% improvement < 5%). Verify should_suggest=False.

9. **`test_format_whatsapp_summary_healthy`** -- No drifted entities, all stages passed. Verify message contains "All models healthy". Verify message length < 500 chars.

10. **`test_format_whatsapp_summary_with_drift`** -- Two drifted entities. Verify message contains "DRIFT DETECTED" and both entity names. Verify length < 500 chars.

11. **`test_format_whatsapp_summary_with_stage_failure`** -- One stage failed. Verify message mentions the failed stage name.
