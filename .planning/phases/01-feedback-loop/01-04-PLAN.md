1. First, check current state of trade logs to establish a baseline:
   ```
   python3 -c "import json; [print(f'{f}: {sum(1 for t in json.load(open(\"data/\" + f)) if t.get(\"settlement_result\") is not None)} settled') for f in ['kalshi-trades.json','kalshi-strategy-trades.json','beatrelease-trades.json'] if __import__('pathlib').Path('data/' + f).exists()]"
   ```

2. Run settlement reconciliation (write mode, NOT --dry-run):
   ```
   npm run reconcile
   ```
   This calls `python3 scripts/reconcile-trades.py` which fetches settlements from Kalshi API and annotates trade logs with settlement_result fields.

3. Run backfill for remaining gaps:
   ```
   npm run backfill
   ```
   This calls `python3 scripts/backfill-settlements.py` which queries individual /markets/{ticker} endpoints for trades still missing settlement data.

4. Run backtest with --save to persist results:
   ```
   python3 scripts/backtest.py --save
   ```
   This computes Brier scores per bot, per market type, per city, and calibration curves, then writes to data/backtest-results.json.

5. Run performance analysis with reconciliation and save:
   ```
   python3 scripts/analyze-performance.py --reconcile --save
   ```
   This computes daily/weekly/cumulative P&L, rolling Sharpe, gross/net separation, then writes to data/performance-metrics.json.

6. Run calibration with --save:
   ```
   python3 scripts/calibrate-sigma.py --save
   ```
   This runs grid search with Brier-primary optimization and writes per-city sigma parameters to config/calibration.json.

After each command, check its exit code. If reconcile or backfill fails with auth errors, document the error clearly for human verification.

IMPORTANT: The system is in demo mode (KALSHI_MODE=demo). Demo API may have limited settlement data. If reconcile finds 0 settlements, that is an API data limitation, not a code bug. Document what happened.

After the full pipeline, verify the output:

- Check that data/backtest-results.json has per_market_type_brier key
- Check that data/performance-metrics.json exists
