**Helper functions:**

1. `find_nearest_candle_close(candles, target_ts)`:
   - Binary search through sorted candles to find the closest candle to `target_ts`.
   - Return the close price (index 4 in candle array). Return None if no candle within 30 minutes.

2. `compute_rv_at_time(candles, target_ts, lookback_hours=24)`:
   - Filter candles in `[target_ts - lookback_hours*3600, target_ts]`.
   - Compute log returns from consecutive close prices.
   - Need at least 5 candles (3 returns minimum).
   - Annualize: `intervals_per_year = 365.25 * 24 * 4` (15-min intervals).
   - Clamp to [0.10, 3.0]. Return None if insufficient data.
   - This uses the same math as `compute_realized_vol()` in crypto-bot.py but on regular 15-min intervals (avoiding the irregular-interval bias from Pitfall 5 in research).

3. `find_dvol_at_time(dvol_data, target_ts)`:
   - `dvol_data` is `[[timestamp_ms, open, high, low, close], ...]`.
   - Find closest DVOL point to `target_ts` (in seconds). Convert to/from milliseconds.
   - Return close value / 100 (DVOL is in percentage, convert to decimal).
   - Return None if no DVOL point within 2 hours.

4. `parse_iso_ts(iso_string)`:
   - Parse ISO 8601 timestamp (handle Z suffix) to Unix timestamp (seconds).
   - Use `datetime.fromisoformat(s.replace("Z", "+00:00")).timestamp()`.

**Main replay function (`replay_market`):**
- For each settled market: parse ticker, find spot price at open_time from candles, compute actual settlement duration, get IV from DVOL cache, compute RV from candles, blend vol per `vol_config`, call `crypto_price_probability()`.
- Handle bracket markets (direction "B"): compute P(above low) - P(above high) using `_parse_bracket_range`-style logic. For backtesting, use the market title/subtitle to extract bracket range, or default to 1000 (BTC) / 100 (ETH) / 10 (SOL).
- Determine actual outcome from `market["result"]`: "yes"/"all_yes" = 1, "no"/"all_no" = 0, skip empty/voided.
- Return prediction dict: `{"ticker", "asset", "model_prob", "actual", "vol_used", "iv", "rv", "minutes_to_settle", "spot_at_open", "threshold", "direction"}`.

**Backtest runner (`run_backtest`):**
- Load all three caches. Error if any missing.
- Build candles_by_asset dict (BTC, ETH, SOL).
- Build dvol_by_asset dict (BTC, ETH only).
- Default vol_config: `{"iv_weight": 0.6, "rv_lookback_hours": 24}` (matches production).
- Replay each market, collect predictions. Skip markets where spot price or vol is unavailable.
- Compute aggregate Brier score via `brier_score()`.
- Compute per-asset Brier scores.
- Compute calibration table via `calibration_table()`.
- Save raw predictions to `data/crypto-validation/crypto-backtest-raw.json`.

**Vol benchmark (inline in backtest):**
- For each market where both IV (from DVOL) and RV (computed from candles) are available, collect time series pairs: `(timestamp, our_rv, deribit_dvol)`.
- Compute and print:
  - Mean absolute error: `MAE = mean(|our_rv - dvol|)`.
  - Rolling 7-day correlation (if 50+ pairs).
  - Side-by-side summary table: asset, mean_rv, mean_dvol, MAE, correlation.
- This satisfies CRYP-03 (realized vol benchmarked against Deribit DVOL).
