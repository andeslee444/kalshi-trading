### weather-bot.py — Add calibration-gated tiered sizing

The weather bot currently uses a 3-tier sizing system:
- Bracket markets -> `quarter_kelly` (already correct, SIZE-03 compliant)
- High-conviction threshold-NO (>80% model prob) -> `high_conviction_kelly` (60%)
- Standard threshold markets -> `half_kelly`

SIZE-03 says "quarter-Kelly until calibration-validated." The weather bot has a calibration pipeline (Phase 1) that populates `config/calibration.json` with per-city sigma params. When calibration exists, the model IS validated and should keep the current tiered approach. When it does NOT exist, default to quarter-Kelly.

**Implementation:**

1. **Import line 10:** Add `_load_calibration` to the imports (keep all existing imports: `half_kelly, quarter_kelly, high_conviction_kelly`).

2. **Around line 324-346 (sizing block):** Wrap the existing tiered sizing in a calibration check. Replace the current code:
   ```python
   # Position sizing based on market type and conviction
   fee = kalshi_fee_cents(price)
   if is_bracket:
       # Quarter-Kelly for brackets (already SIZE-03 compliant)
       count, risk, kelly_details = quarter_kelly(...)
       sizing_label = "quarter-Kelly"
   elif side == "no" and (1 - opp["our_prob"]) > 0.80:
       count, risk, kelly_details = high_conviction_kelly(...)
       sizing_label = "60%-Kelly (high-conviction)"
   else:
       count, risk, kelly_details = half_kelly(...)
       sizing_label = "half-Kelly"
   ```

   With calibration-gated version:
   ```python
   # Position sizing based on market type, conviction, and calibration status
   fee = kalshi_fee_cents(price)
   cal = _load_calibration()
   city_code = opp["parsed"]["city"]
   is_calibrated = bool(cal.get("weather", {}).get("per_city", {}).get(city_code))

   if is_bracket:
       # Rec 3+10: Quarter-Kelly for brackets (always, regardless of calibration)
       count, risk, kelly_details = quarter_kelly(
           edge, price, budget.max_cost_cents,
           bankroll_cents=budget.bankroll_cents, fee_cents=fee, return_details=True,
       )
       sizing_label = "quarter-Kelly"
   elif is_calibrated and side == "no" and (1 - opp["our_prob"]) > 0.80:
       # Calibration-validated: high-conviction threshold-NO -> 60% Kelly
       count, risk, kelly_details = high_conviction_kelly(
           edge, price, budget.max_cost_cents,
           bankroll_cents=budget.bankroll_cents, fee_cents=fee, return_details=True,
       )
       sizing_label = "60%-Kelly (high-conviction, calibrated)"
   elif is_calibrated:
       # Calibration-validated: standard threshold -> half-Kelly
       count, risk, kelly_details = half_kelly(
           edge, price, budget.max_cost_cents,
           bankroll_cents=budget.bankroll_cents, fee_cents=fee, return_details=True,
       )
       sizing_label = "half-Kelly (calibrated)"
   else:
       # Not calibrated: default to quarter-Kelly (SIZE-03)
       count, risk, kelly_details = quarter_kelly(
           edge, price, budget.max_cost_cents,
           bankroll_cents=budget.bankroll_cents, fee_cents=fee, return_details=True,
       )
       sizing_label = "quarter-Kelly (uncalibrated)"
   ```

Move the `city_code = opp["parsed"]["city"]` extraction up into the sizing block (before the calibration check).
