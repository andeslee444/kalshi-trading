# Weather Bot (weather_bot.py)

Forecast-based temperature trading on KXHIGH markets. Daemon bot scanning every 5-30 min (adaptive).

## What it does

Fetches ensemble weather forecasts (GFS, ECMWF, ICON, NBM, AIFS, GraphCast) from Open-Meteo, computes win probability via Bayesian Model Averaging, and places trades on Kalshi KXHIGH temperature markets when edge exceeds threshold.

## Key functions

- `get_weather_markets(cache_ttl)` — Fetches markets by `series_ticker` per city. Uses `_weather_series_ticker()` for T-prefix handling.
- `scan_and_trade()` — Main scan loop: fetch markets → fetch forecasts → evaluate edge → place trades
- `_weather_series_ticker(city_code)` — Returns `KXHIGHT{city}` for T-prefix cities, `KXHIGH{city}` for originals

## Kalshi ticker format

Two naming conventions coexist:
- **Original 8 cities** (KXHIGH{city}): AUS, CHI, DEN, LAX, MIA, NY, PHIL
- **T-prefix cities** (KXHIGHT{city}): ATL, BOS, DAL, DC, HOU, LV, MIN, NOLA, OKC, PHX, SATX, SEA, SFO

The `_T_PREFIX_CITIES` set and `_weather_series_ticker()` handle this. The ticker parser in `ticker_utils.py` strips the T prefix — e.g., `KXHIGHTATL-26APR14-T91` parses to `city: "ATL"`.

## Config

- `config/kalshi-config.json` — cities, edge thresholds, risk limits, ensemble settings, maker execution params
- `config/calibration.json` — per-city sigma parameters (generated by `npm run calibrate`)
- `config/bots-config.json` → `weather` section — enabled flag, exit params

### Key config flags

- `disableWeatherYes: true` — **Must stay true on prod.** YES-side has 5% win rate on demo (3W/54L, -$244). NO-side is 80% WR, +$2,329.
- `maxRestingSeconds: 900` — Maker order TTL. Was 300 (5 min) but 73% of orders expired unfilled. Increased to 900 (15 min).
- `yieldSameDayToObservedWeather: true` — Defers day-0 markets to source monitor's NWS observation-based trading
- `cityEdgeThresholds` — Per-city edge overrides (e.g., NY at 12% vs default 6%)

## Production findings (Apr 2026)

- NO-side is the only profitable side. YES-side is disabled.
- Day-0 and Day-1 forecasts are both profitable (Day-1 higher ROI at +331%)
- 59% of maker orders go to rest, only 19% of resting contracts fill
- AUS and DEN are strongest cities; MIA is unprofitable on forecasts (but profitable on NWS monitor)
