```
TASK SPEC:
[Paste the FULL text of the task from the plan — every line, every code block]

INSTRUCTIONS:
1. Follow the task spec EXACTLY — implement what it says, nothing more, nothing less.
2. Use TDD: write failing test first, verify it fails, implement, verify it passes.
3. Run `pytest tests/ -v --tb=short` after implementation to verify no regressions.
4. Commit with the exact message from the spec using --author flag.
5. If something in the spec doesn't work (wrong line numbers, missing imports, etc.), fix it pragmatically but stay faithful to the intent.
6. Do NOT read the plan file — everything you need is in this prompt.
7. After completing, report: what you did, test results, commit SHA.
```

### Step 2: Dispatch Spec Reviewer Subagent

After implementer completes, dispatch `subagent_type: "superpowers:code-reviewer"`:

```
Review the implementation of Task N against its spec.

TASK SPEC:
[Paste the same full task text]

RECENT COMMIT: [SHA from implementer]

Check:
1. Does the code match what the spec asked for? (functions, signatures, behavior)
2. Is anything MISSING that the spec requires?
3. Is anything EXTRA that the spec didn't ask for?
4. Do the tests cover what the spec describes?

Report: ✅ SPEC COMPLIANT or ❌ ISSUES: [list each gap]
```

### Step 3: Dispatch Code Quality Reviewer (only after spec passes)

Dispatch `subagent_type: "superpowers:code-reviewer"`:

```
Review code quality for Task N implementation.

RECENT COMMIT(S): [SHAs]
FILES CHANGED: [list files]

Check:
1. Are there any bugs or logic errors?
2. Is error handling adequate?
3. Are tests meaningful (not just smoke tests)?
4. Does the code follow existing project patterns?
5. Any security issues?

Report: ✅ APPROVED or list issues by severity (Critical/Important/Minor).
Only flag issues you're confident about (>85%).
```

### Step 4: Fix Issues (if any reviewer found problems)

Resume the implementer subagent to fix issues, then re-run the relevant reviewer.

### Step 5: Mark Task Complete

Update the TodoWrite task status to completed, then proceed to next task.
