# Weather Bot Bias Correction & Recalibration Design

## Problem Statement

Historical forecast calibration (14,177 forecast-actual pairs across 20 cities, 180 days) reveals massive systematic warm bias in all NWP models used by the weather bot. Every model over-predicts temperatures for every city, with biases ranging from +3.7F (Seattle/GraphCast) to +18.5F (Denver/ECMWF).

This bias is the dominant source of forecast error. With current sigma=4.7F, a +10F bias means forecasts are systematically off by 2+ sigma, producing probability estimates that are directionally wrong. Correcting this bias is the single highest-impact improvement available.

## Current Implementation Note

This document captures the original bias-correction design direction.
The current runtime has evolved in one important way:

- the live weather bot now prefers `config/weather-live-bias.json` as the calibration prior
- that artifact is built from `data/weather-training.db` via `scripts/backfill-weather-data.py` and `scripts/calibrate-weather-bias.py`

### Root Cause

NWP models operate on grid cells (9-25km resolution). The model's surface elevation for a grid cell is smoothed topography, not the actual station elevation. For cities near complex terrain (Denver at 5,431 ft on the Front Range, Austin/OKC/SATX on the Edwards Plateau/Great Plains), the model grid cell is at lower elevation than the ASOS station, producing systematically warmer temperature predictions. Coastal/flat cities (SEA, MIA, HOU) have smaller biases because terrain smoothing matters less.

### Data Source

`config/historical-calibration.json` — generated by `scripts/calibrate-historical.py` from Open-Meteo Historical Forecast API vs IEM ASOS actuals. 4 models calibrated (GFS, ECMWF, ICON, GraphCast). NBM and AIFS unavailable on the historical forecast API.

## Architecture

```
historical-calibration.json ──► BiasCorrector (weather_data.py)
                                      │
                                      ├── correct parametric ensemble temps
                                      │   (per-model correction before ensemble_weather_probability_v2)
                                      │
                                      ├── correct empirical ensemble bias_offset
                                      │   (city-average bias for EnsembleCollector members)
                                      │
                                      └── correct single-model fallback temps
                                          (before compute_probability)

ForecastVerifier (live 30-day) ──► blended with historical bias
                                   (live data takes priority as it accumulates)
```

## Section 1: Per-City, Per-Model Bias Correction

### 1.1 BiasCorrector Class (weather_data.py)

```python
class BiasCorrector:
    """Corrects systematic forecast bias using historical calibration data.

    Loads per-city, per-model bias from config/historical-calibration.json
    and applies correction: corrected_temp = raw_temp - bias.
    """

    def __init__(self, calibration_path=None, logger=None):
        self.log = logger or _log
        self._data = {}
        self._load(calibration_path)

    def _load(self, path=None):
        if path is None:
            path = Path(__file__).resolve().parent.parent.parent / "config" / "historical-calibration.json"
        try:
            if Path(path).exists():
                self._data = json.loads(Path(path).read_text())
                n = self._data.get("n_forecasts", 0)
                self.log.info("BiasCorrector loaded: %d forecast pairs", n)
        except Exception as e:
            self.log.warning("BiasCorrector: failed to load calibration: %s", e)

    def correct(self, city, model, temp):
        """Apply per-city, per-model bias correction.

        Returns corrected_temp = raw_temp - bias.
        Falls back to city average bias if model not calibrated.
        Returns raw temp if no calibration data available.
        """
        if temp is None:
            return None
        bias = self._get_bias(city, model)
        return temp - bias

    def correct_forecast_dict(self, city, forecasts):
        """Correct all model temps in a {model: temp} dict.

        Returns new dict with corrected temperatures.
        """
        return {
            model: self.correct(city, model, temp)
            for model, temp in forecasts.items()
        }

    def city_average_bias(self, city):
        """Average bias across all calibrated models for a city.

        Used for ensemble members where individual model attribution
        is not possible (GEFS + ECMWF EPS mixed members).
        """
        per_city = self._data.get("per_city", {}).get(city, {})
        if not per_city:
            return self._global_average_bias()
        biases = [m["bias"] for m in per_city.values() if "bias" in m]
        return sum(biases) / len(biases) if biases else 0.0

    def residual_std(self, city, model=None):
        """Compute residual std: sqrt(RMSE^2 - bias^2).

        This is the forecast uncertainty AFTER bias removal.
        If model is None, returns weighted average across models.
        """
        per_city = self._data.get("per_city", {}).get(city, {})
        if model and model in per_city:
            stats = per_city[model]
            return self._compute_residual(stats)

        # Average across all models for this city
        residuals = []
        for m_stats in per_city.values():
            r = self._compute_residual(m_stats)
            if r is not None:
                residuals.append(r)
        if residuals:
            return sum(residuals) / len(residuals)

        # Fall back to global
        return self._global_residual_std()

    def _get_bias(self, city, model):
        per_city = self._data.get("per_city", {}).get(city, {})
        if model in per_city:
            return per_city[model].get("bias", 0.0)
        # Fall back to city average
        if per_city:
            return self.city_average_bias(city)
        # Fall back to global model bias
        global_stats = self._data.get("global", {}).get(model, {})
        return global_stats.get("bias", 0.0)

    def _global_average_bias(self):
        global_stats = self._data.get("global", {})
        biases = [m["bias"] for m in global_stats.values() if "bias" in m]
        return sum(biases) / len(biases) if biases else 0.0

    def _compute_residual(self, stats):
        if not stats or "rmse" not in stats or "bias" not in stats:
            return None
        rmse, bias = stats["rmse"], stats["bias"]
        sq = rmse ** 2 - bias ** 2
        return math.sqrt(max(0, sq))

    def _global_residual_std(self):
        global_stats = self._data.get("global", {})
        residuals = [self._compute_residual(s) for s in global_stats.values()]
        residuals = [r for r in residuals if r is not None]
        return sum(residuals) / len(residuals) if residuals else 4.7
```

### 1.2 Apply in weather-bot.py

**Module-level initialization** (after other fetcher instantiation):
```python
from weather_data import BiasCorrector
bias_corrector = BiasCorrector(logger=log)
```

**Three correction points in scan_and_trade():**

**Point A — Parametric ensemble (before ensemble_weather_probability_v2):**
```python
# Before: parametric_data = dict(forecast_data)
# After:
parametric_data = bias_corrector.correct_forecast_dict(city, dict(forecast_data))
```

**Point B — Empirical ensemble (bias_offset parameter):**
```python
# Before: bias = city_bias.get(city, {}).get("bias_f", 0.0) if city_bias else 0.0
# After: blend historical + live bias
hist_bias = bias_corrector.city_average_bias(city)
live_bias = city_bias.get(city, {}).get("bias_f", 0.0) if city_bias else 0.0
live_n = city_bias.get(city, {}).get("n", 0) if city_bias else 0
# Blend: live takes over as data accumulates (n >= 20 = fully live)
alpha = min(1.0, live_n / 20.0) if live_n > 0 else 0.0
bias = alpha * live_bias + (1 - alpha) * hist_bias
```

**Point C — Single-model fallback:**
```python
# Before: our_prob = compute_probability(forecast_temp, ...)
# After:
corrected_temp = bias_corrector.correct(city, model_key, forecast_temp)
our_prob = compute_probability(corrected_temp, ...)
```

**Point D — forecast_temp for logging and near-threshold filter:**
```python
# The mean forecast_temp used for logging and distance calculations
# should also be bias-corrected for consistency
corrected_temps = [bias_corrector.correct(city, m, t) for m, t in forecast_data.items() if t is not None]
forecast_temp = sum(corrected_temps) / len(corrected_temps) if corrected_temps else None
```

### 1.3 HRRR/NAM Injection

HRRR and NAM are short-range mesoscale models with different bias characteristics from the global models. They are NOT in the historical calibration (which only covers GFS, ECMWF, ICON, GraphCast).

**Approach:** Do NOT bias-correct HRRR/NAM temperatures. These models already run at high resolution (3km) with better terrain representation. Their injection weights (HRRR 60%/30%, NAM 40%/20%) already account for their accuracy advantage at short range. The empirical bias_offset will implicitly handle any HRRR/NAM bias since it's applied to all members equally.

**Physical interpretation:** Desert/coastal cities (SEA, LV, PHX, SFO) have low residual std (3.2-3.8F) because weather patterns are more predictable. Continental/Great Plains cities (MIN, DEN, OKC, CHI) have high residual std (6.0-6.7F) because frontal passages create abrupt temperature swings.

### 2.2 Enhance calibrate-historical.py

Add `--write-sigma` flag that:
1. Computes per-city residual_std (weighted average across models using inverse-MAE weights)
2. Applies Bayesian shrinkage toward global average: `sigma = (n * city_std + k * global_std) / (n + k)` with k=15
3. Writes sigma values to `config/calibration.json` in existing format:
   ```json
   "weather": {
     "global_sigma_intercept": 4.93,
     "per_city": {
       "SEA": {"sigma_intercept": 3.45, "n": 178, "shrinkage_weight": 0.922},
       ...
     }
   }
   ```
4. Preserves existing calibration.json fields (Brier scores, ensemble weights, etc.)

### 2.3 Sigma Slope

Current slope=0.2 (from calibrate-sigma.py). Historical calibration doesn't break down by lead time yet, so we keep slope=0.2 as initial value. Future enhancement: historical calibration with lead-time stratification to compute empirical slope.

## Section 3: Evidence-Based Weights + Operational Config

### 3.1 Update Ensemble Weights

Historical inverse-MAE optimal weights: GraphCast 27.9%, ECMWF 25.3%, ICON 24.1%, GFS 22.7%.

Note: These weights are from RAW (uncorrected) MAE. After bias correction, models with large bias may have been penalized disproportionately. The relative ranking could shift. However, GraphCast's superiority is robust — it has both the lowest bias AND lowest residual_std in most cities.

Updated weights for `config/kalshi-config.json`:

```json
"weights": {
    "graphcast": 0.25,
    "ecmwf": 0.23,
    "icon": 0.20,
    "gfs": 0.20,
    "nbm": 0.08,
    "aifs": 0.04
}
```

NBM reduced from 30% to 8% (no historical calibration, unvalidated). AIFS reduced from 12% to 4% (same reason). Both will increase as ForecastVerifier accumulates live accuracy data for them.

### 3.2 Enable Convergence Signal

Set `previousRuns.enabled: true` in kalshi-config.json. The code is already implemented and tested from the premium API upgrade. This provides Kelly sizing adjustment based on forecast stability.

### 3.4 Validation Plan

1. **Sanity check:** Run `calibrate-historical.py --write-sigma` and verify sigma values are physically reasonable
2. **Demo mode test:** Run bot in demo mode, log both raw and corrected probabilities for 1 scan cycle
3. **A/B comparison:** Compare corrected vs uncorrected probability against market price (closer to market = better calibrated)
4. **First 50 trades:** Monitor Brier score of bias-corrected trades vs historical Brier (0.314)
5. **Re-calibrate:** After 2-4 weeks of bias-corrected trading, re-run calibrate-sigma.py for refined sigma

## Risk Assessment

| Risk | Mitigation |
|------|-----------|
| Historical API bias differs from real-time API bias | Blend with ForecastVerifier live bias; historical is prior, live overrides |
| Overcorrection flips bias from warm to cold | Monitor first 50 trades; BiasCorrector can be disabled via config |
| Sigma too tight after correction → overconfident bets | Bayesian shrinkage prevents extreme sigma values; min sigma floor of 0.5F |
| NBM/AIFS weight too low | ForecastVerifier adaptive weights will increase as live data accumulates |
| Breaking existing functionality | All changes additive; BiasCorrector returns raw temp if no calibration data |

## Rollback

| Change | Rollback |
|--------|----------|
| BiasCorrector | Delete `config/historical-calibration.json` — corrector returns raw temps |
| Sigma values | Restore previous `config/calibration.json` from git |
| Ensemble weights | Revert `kalshi-config.json` weights section |
| previousRuns enabled | Set `"enabled": false` |
